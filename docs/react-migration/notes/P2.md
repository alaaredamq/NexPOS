## Behaviour decisions
1. **Main screen chip.** The grid default is `GET pos/products?mainScreen=true`; the first chip says "Main screen" when the shop has a display order, else "All products" (server `isMainScreen`). Category chips carry the palette dot and product count.
2. **Scanning.** The scan box is always focused: a printable key with nothing editable focused moves focus there first (so the first digit of a scan is not lost), a click on the page returns focus, so does `posBus.focusScan()`. Enter → `GET pos/products/search?q&barcodeOnly=true`. Port of POS.js: `5*` / `5x` alone remembers a quantity for the **next** scan only (badge, tap to forget); `5*123` sells 5; QR-ish input (links, mail, vCard, Wi-Fi, JSON, >50 chars, odd characters) is refused locally.
3. **Rapid keystrokes.** `KeystrokeTimer` (≥6 chars, average gap ≤35 ms) is used by the *search* box only: if a scanner's burst lands there, Enter does a barcode lookup instead of a name search.
4. **Tile = price from the server, as is.** No client discount maths; the supplier discount is shown only in the price-check dialog (informational, per P1). Low-stock threshold = `minimumStock ?? 5` (see below). A sold-out tile stays pressable.
5. **Shortcuts** (the old page only had Alt+D/I/O/P, kept): F2 search, F3 price check, F4 held carts, F6 hold, F7 manual item, F8 discount, F9 clear cart, Ctrl+Enter checkout, Esc (closes the search list, then clears it). F5/F11/F12 untouched. List behind the `?` button.
6. **Price check** is P2's (needs only the catalog): barcode answers straight away, a name lists matches. Never shows cost.
7. **Layout.** Cart column `clamp(380px, 30vw, 460px)` (340 px under 1100 px) | catalog; stacks under 860 px with a "review cart" button (badge = `cartCount`). The scan box switches to the small ScanInput under 1100 px so the placeholder is not covered by the "scanner ready" pill. Electron zoom is the main process's job (1500 px / 0.8, nothing in the SPA).
8. **Dropped from the Razor page:** the clock-driven notification badge in the POS bar (the shell's bell is not in the bare layout; I2 can add it), jQuery-UI autocomplete, cache refresh calls (P1 dropped them).
