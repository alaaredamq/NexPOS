# 0B — Client scaffold: handoff notes

**Branch:** `react/0B` (merged into `react/main` when reviewed). **Status:** ☑ done.

## What exists
- `client/` — Vite 8 + React 19 + TypeScript (strict, `noUncheckedIndexedAccess`) + oxlint + Vitest (jsdom, globals) +
  Testing Library + Playwright config. `base: '/app/'`, build → `Web/wwwroot/app` (gitignored), dev server `:5173`
  proxying `/api` → `http://localhost:5000`.
- Skeleton folders per §3 (`app api core ui shell styles locales modules e2e`); `app/routes.tsx` auto-discovers
  `modules/*/routes.tsx` (default export = `RouteObject[]`). `app/App.tsx` is a throw-away placeholder for 0D.
- Fonts self-hosted in `client/src/assets/fonts` (Public Sans, JetBrains Mono, Archivo + OFL licences), `@font-face` in
  `styles/fonts.css`. `styles/tokens.css` is BoussiCell's, verbatim (D9), plus `styles/theme.css` NexPOS overrides.
- Dependencies for D2 are installed (Query, react-hook-form, zod, i18next, react-i18next, zustand, router) but unused yet.
- `npm run build` ends with `scripts/check-bundle-budget.mjs` (entry ≤ 250 KB gzip; route budgets get added to
  `ROUTE_BUDGETS` by the tracks that own them). Currently 96 KB.
- `npm run lint` also runs `scripts/check-logical-css.mjs` — the RTL guard promised for 0C (physical `left/right`,
  `margin-left`, `text-align:left`, `float`). Escape hatch `/* rtl-ok */`. It scans `client/src/**/*.css` only.
- `docs/react-migration/baseline.md` — measurements of the current app (D12 "before").

## Not done / deliberately deferred
- `npm run api:types` is a stub that fails with a message — it needs `swagger.json` from 0A.
- Playwright has config but no spec yet (`e2e/` empty); each track adds its own.
- `global.css` is intentionally minimal; 0C owns it from here (it does not copy BoussiCell's `user-select:none` — decide in 0C).

## Odd / watch

  (REACT_MIGRATION.md updated accordingly).
- Fonts were copied from `Web/wwwroot/fonts/boussi/` (now tracked on master) into `client/src/assets/fonts`.
- **Brand colour:** NexPOS is teal (`#0a7b85`), BoussiCell is blue. `styles/tokens.css` is BoussiCell's verbatim (D9); the 14 values
  that differ live in `styles/theme.css` (same shared-tokens + per-app-theme split BoussiCell uses). Source of truth for
  those values is the restyled `Web/wwwroot/css/colors.css`; rebranding = edit `theme.css` only.
- The two Playwright/npm installs are large; `client/node_modules` is gitignored. Run `npm ci` inside `client/`.
