# 0C — Design system: handoff notes

**Branch:** `react/0C` (off `react/main`). **Status:** ◑ in review. Everything lives in `client/src/ui/**` + `client/src/styles/global.css`.

## Import style
No barrel. Import per file: `import { Button } from '@/ui/Button'`, `import { MoneyField } from '@/ui/form/MoneyField'`.
Mount `<UiHost />` (`ui/UiHost.tsx`) **once** in the shell (0D): it hosts `toast.*`, `confirm()` and the context menu.

## Decisions / things to know
- **Text is selectable by default** (BoussiCell sets `user-select:none` on body). Back-office needs copyable SKUs/order numbers; POS touch surfaces add `.no-select`.
- **Money = `<notation> 1,234.50`, Latin digits in both languages** — the Razor app never used Arabic-Indic numerals (`localization.js` only swaps strings; POS.js prints `notation + toFixed(2)`). Rounding is **half-to-even** because C# `Math.Round(decimal, n)` is. The browser still never decides a total (D10/P1 trap); `MoneyField` is for entering prices/amounts. Arabic-Indic digits typed by the user are accepted and normalised.
- **Component text** comes from `useTranslation()` with English default values, so `ui/` works with no i18n setup. **0E: seed these `common.*` keys** (full list with Arabic in `ui/kit/kitI18n.ts`): loading, cancel, close, dismiss, working, actionFailed, search, clearSearch, clearSelection, noMatches, loadFailed, pagination, pageRange, previousPage, nextPage, goToPage, rowsPerPage, columns, actions, retry, noResults, managerPinTitle/Subtitle/Error, pinEntered, clear, backspace, scannerReady, scanReady, decreaseQty, increaseQty, dateRange, from, to, today, last7Days, last30Days, thisMonth. Delete the duplicate in `kitI18n.ts` once 0E lands (tests/kit can keep using it).
- **`ManagerPinModal` takes `verify(pin)`** instead of importing the auth store, so `ui/` has no dependency on `core/`. 0D wires it to the session/auth API.
- **Tokens:** `styles/tokens.css` untouched (verbatim). Added to `StatusBadge` a generic `info` tone (BoussiCell's `tradein` tone is domain-specific and not used here).
- **`DataTable`** is controlled and server-driven: parent owns page/sort/search (mirror them in the URL) and passes one page of rows. Sort cycles asc → desc → none (`aria-sort`). Optional `columnChooserKey` persists hidden columns in localStorage; `virtualize={{rowHeight,maxHeight}}` windows long pages; `hideBelow` drops columns at narrow widths. P2's tile grid should use TanStack Virtual (not installed yet) — `useVirtualRows` is rows-only on purpose.
- **`Select`** popup is portalled + `position: fixed`, so modals/tables can't clip it. Escape closes the popup first and does not reach an enclosing `Modal`. For edit screens with async options pass `initialLabel`.
- **Escape key priority:** PinPad ignores Escape when empty so a Modal around it still closes.
- **Bidi:** user data (names, phone numbers, SKUs) inside RTL pages should be wrapped in `<bdi>` (Select does it) or the mixed run scrambles ("+961 3 123 456" rendered reversed in the first screenshot pass). Numbers/money use `ltrIsolate` (inside `formatMoney`).
- CSS Modules scope `@keyframes` names — a keyframe referenced from a module must be defined in that same file (BoussiCell's `ScanInput` referenced a global `pulse`; fixed here).
- `App.tsx` placeholder got an `<Outlet />` so `/app/_kit` renders; 0D replaces that file anyway.

## Verified
`tsc -b`, `oxlint` + RTL guard (`check-logical-css`), 42 Vitest tests (format/rounding, window maths, Modal focus trap, confirm/toast, PIN modal, DataTable sort/empty/error/actions/chooser, Pagination, SearchBox debounce, Select keyboard/async, form fields + server-error mapping), production build (entry 96.6 KB gzip; `_kit` is excluded from the bundle). ## Not done / for later
- No dark-mode theme (only the dark/light *rail* tokens exist).
- Playwright e2e for the kit: not added (no flows yet; `/app/_kit` is dev-only).
- Calendar is the native `<input type=date>` (follows OS locale, fine in RTL); a custom popup calendar was not worth the weight.
- Tooltips use the native `title` (IconButton). No custom tooltip component yet.
